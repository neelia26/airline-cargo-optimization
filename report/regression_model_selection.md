# Regression Model Selection

## Purpose

The regression model estimates the fuel consumed by a Boeing 777-300ER flight from Colombo to Dubai. Its prediction can later allow the genetic algorithm to consider how different cargo selections affect zero-fuel mass and, therefore, expected fuel consumption.

## Experimental method

The 5,000 OpenAP-generated records were divided reproducibly using random seed `4607`:

- 4,250 records (85%) formed the development set.
- 750 records (15%) formed the held-out test set.
- Five-fold cross-validation on the development set was used for model and hyperparameter selection.
- The test set was not used during selection; it was used once for final confirmation.

All models received the same five inputs: zero-fuel mass, cruise speed, cruise altitude, temperature deviation and flight duration. The target was fuel consumption in kilograms. RMSE was the primary metric because large fuel errors should be penalised more heavily. MAE gives the average absolute error, while R² describes how much variation in fuel consumption the model explains.

## Results

|---:|---|---:|---:|---:|---:|---:|---:|
| 1 | Support Vector Regression | 29.47 | 22.83 | 0.99896 | 27.62 | 21.88 | 0.99914 |
| 2 | Polynomial Regression | 32.87 | 26.15 | 0.99870 | 31.70 | 25.76 | 0.99887 |
| 3 | Gradient Boosting Regression | 78.69 | 62.73 | 0.99255 | 75.50 | 60.61 | 0.99359 |
| 4 | Random Forest Regression | 115.97 | 90.52 | 0.98382 | 106.48 | 82.85 | 0.98726 |
| 5 | Multiple Linear Regression | 145.57 | 105.75 | 0.97453 | 135.96 | 102.66 | 0.97922 |

## Selected model

Support Vector Regression (SVR) was selected because it achieved the lowest five-fold cross-validated RMSE: 29.47 kg. It also achieved the best held-out results, with an RMSE of 27.62 kg, an MAE of 21.88 kg and an R² of 0.99914. The selected RBF-kernel pipeline standardises the five inputs and uses `C=1000`, `epsilon=10` and `gamma=0.1`.

Polynomial Regression was a close second and predicted considerably faster, but speed was not used as a post-hoc reason to override the stated accuracy criterion. SVR required about 88 ms to predict all 750 test records (about 0.118 ms per record), which remains practical when predictions are passed to the genetic algorithm in batches.

These very high scores should be interpreted in context: the target was generated by OpenAP, so the model is learning a controlled simulation rather than noisy measurements from operational airline flights. Therefore, the reported accuracy demonstrates fidelity to this simulated environment and should not be claimed as real-world airline accuracy.
